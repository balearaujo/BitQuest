# BitQuest
BitQuest por vale y miri

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
## INTRUCCIONES DE CONFIGURACION, COMPILACION Y EJECUCION DESDE CONSOLA
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Para poder compilar el proyecto correctamente
es necesario contar con las siguientes herramientas instaladas y configuradas
en las variables de entorno del sistema:

* NASM: Compilador para el código en ensamblador de 64 bits (rutinas de bajo nivel).
* GCC: Compilador de C para la lógica principal del juego.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
## CONFIGURACION DEL ENTORNO
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. Abrir la terminal de su sistema (por ejemplo, PowerShell o CMD en Windows).
2. Navegar hasta la carpeta raíz que contiene todos los archivos del juego utilizando el comando `cd`.
Por ejemplo:
   `cd Desktop\BitQuest`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
## COMPILACION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Dentro de la carpeta raíz del proyecto en la terminal, ejecute el siguiente comando:
      `.\build.bat`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
##EJECUCION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Ejecutar el siguiente comando para ejecutar el juego:
      `.\BitQuest.exe`
